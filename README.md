# Crafteo · Catálogo

Catálogo estático en español para Crafteo 3D, Asunción. No necesita instalar dependencias ni ejecutar un build. El sitio vive en la raíz del repositorio.

- Editar productos, precios, enlaces de WhatsApp y datos de contacto en `index.html`.
- Guardar las fotos optimizadas de cada producto en `img/`.
- Si se agrega una categoría, usar el mismo identificador en `data-filter` y `data-category`.

Para abrir localmente: abrir `index.html` en el navegador. El catálogo completo y sus enlaces funcionan sin JavaScript; los filtros lo usan.

En GitHub Pages, seleccioná Settings → Pages → Deploy from a branch → main → / (root).
